# 人物提示词模板：固定身份与镜头变量

![人物提示词模板：固定身份与镜头变量](cover.png)

这个仓库提供提示词结构及镜头审核清单。角色为虚构成年角色，示例没有对应的模型出图实测。

## 模板

```text
使用已附参考图中的同一位成年角色作为身份依据。
保留面部身份、短发、深色外套、圆形耳饰。

场景：街边咖啡店。
动作：坐在窗边看向窗外。
景别与光线：腰部以上中景、柔和日光。
保持人物可辨认，不重新设计外貌。
```

## 使用条件

- [ ] 已实际附上参考图，接口支持参考图编辑。
- [ ] 保持项符合项目需求；换装任务可调整服装要求。
- [ ] 换镜头时先只改场景或动作，保留身份段。
- [ ] 保留模型版本、素材、提示词和参数。
